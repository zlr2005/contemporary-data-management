```powershell
..\.venv\Scripts\python.exe -m pytest -q
```

本机测试连接为 mongodb://127.0.0.1:27018，需要先启动专用 MongoDB；可先运行系统启动入口。新环境在虚拟环境中安装 requirements-dev.txt 后执行 python -m pytest -q，可通过 TEST_MONGO_URI 修改测试连接。

旧版本详情提供“加入新问卷”；向已有草稿加入版本，进入该草稿后使用选题器。当前未单独提供题目管理页中选择任意目标草稿的弹窗，操作通过原编辑器完成。

### 代码与数据变化

- 新增 app/questions.py 和 app/question_api.py；保留原 SurveyService、ResponseService 及规则处理器，原接口继续可用。
- 新增 question_series、question_versions 两个集合，surveys 允许结构版本 1、2；版本 2 的题目同时保存原内容快照及系列、版本引用。
- question_series.creation_hash 是实现时增加的内部创建请求摘要，与稳定系列 ID 一起支持首次保存中断恢复；不对外返回。
- 版本的业务编号与 schema_version 分开；正式版本接口不提供覆盖、删除操作。
- 填写端继续使用原七字段题目，原 answers 和 submission_key 不变；版本管理元数据不会混入规则引擎严格字段检查。
- 原编辑器增加题目版本保存、版本选择、来源提示及未保存导航保护，保留原直接编题、跳转与预览。
- scripts/migrate_stage2.py 默认只读预览，显式 --apply 才写入。复制只支持空目标，迁移可重复执行。

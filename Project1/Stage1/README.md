## 主要功能

- 账号注册与登录，管理操作检查问卷所有权。
- 创建和发布问卷，配置匿名、重复填写及截止时间。
- 支持单选、多选、文本和数字题，配置必答、数量、长度、格式及数值限制。
- 根据单选、多选和数字条件跳转，按规则顺序首条命中，仅允许向后跳转。
- 后端重新计算有效答题路径，校验答案并保存答卷，支持提交重试和并发防重复。
- 查看整份问卷或单题统计，包括选项次数、填写内容及数字平均值。

## 环境准备与启动

以下以 Windows PowerShell 为例，需要安装 Python 3.10及以上版本（含可用的 pip）和 MongoDB Community Server。将 `mongod` 所在目录加入 PATH；若未加入，可在启动前设置其实际路径：

```powershell
$env:MONGOD_PATH = "你的MongoDB安装目录\bin\mongod.exe"
```

在本 README 所在目录打开终端，进入“代码”目录并准备独立环境：

```powershell
cd 代码
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start.py
```

之后也可双击“代码”目录中的 `启动系统.cmd`（需保证 `python` 命令可用）。启动入口会优先使用已有项目虚拟环境；缺少可用环境时，会尝试创建环境并安装依赖。

启动后访问：

- [问卷系统](http://127.0.0.1:8000)
- [交互式API文档](http://127.0.0.1:8000/docs)

默认连接 `mongodb://127.0.0.1:27018`。该端口没有数据库服务时，启动入口会尝试启动仅监听本机的专用 MongoDB 实例，数据保存在“代码/.data/local-mongo”。应用启动时自动初始化集合校验和索引。

如需连接已有 MongoDB，将“代码/.env.example”复制为同目录下的 `.env`，修改 `MONGO_URI` 和 `MONGO_DATABASE`。详细说明见[配置说明](代码/配置说明.md)。

仓库不包含本机数据库数据。首次运行后请自行注册账号、创建问卷；截图中的测试账号和问卷不会自动出现在新环境中。

## 基本使用流程

1. 注册并登录，创建问卷。
2. 添加题目，设置选项、校验和跳转规则，保存草稿并预览。
3. 发布问卷，在列表中复制分享链接。
4. 登录填写者账号，通过链接填写并正式提交。
5. 切回创建者账号，打开统计页核对选项次数、内容和平均值。

匿名填写仍需登录，匿名表示向创建者隐藏填写者账号身份。默认服务仅监听本机，分享链接用于本机演示；跨电脑访问需要另外部署和配置网络。

## 测试

自动测试脚本位于“代码/tests”，包括规则测试和连接真实 MongoDB 的API测试。先启动系统以确保 MongoDB 可用，再打开另一个终端，在“代码”目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

测试默认连接 `mongodb://127.0.0.1:27018`，可通过环境变量 `TEST_MONGO_URI` 调整。API测试使用随机命名的独立测试数据库，结束后仅清理该测试数据库。

已有测试记录为43项自动测试通过，本 README 整理时未重新执行测试。手工测试覆盖创建问卷、添加题目、跳转、校验、提交及统计，执行记录与截图见[测试用例](测试/测试用例.md)。原操作指南的计划输入与本次实际输入存在差异，实际统计值以测试记录和截图为准。

## 第一阶段范围与后续扩展

第一阶段在首次发布后锁定题目结构和填写设置，仅允许修改标题、说明、截止时间及关闭问卷，不保存服务端未提交答卷草稿。题型、校验和跳转通过数据库配置及通用处理器实现，保留稳定ID和 `schema_version`，便于第二阶段扩展。

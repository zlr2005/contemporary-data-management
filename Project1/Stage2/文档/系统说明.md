# 系统说明

前半部分保留第一阶段说明，第二阶段新增内容追加在后文对应章节；当前运行环境见[配置说明](../代码/配置说明.md)。

## 1. 系统简介

本系统是基于 MongoDB 的简化在线问卷系统。用户登录后可以创建和发布问卷，将链接分享给其他登录用户填写，并查看已提交答卷的统计结果。界面以完成问卷业务为主，支持第一阶段需求，后续可在现有结构上扩展。

## 2. 技术组成

| 部分 | 使用技术 | 作用 |
| --- | --- | --- |
| 前端 | HTML、CSS、JavaScript | 登录、问卷编辑、逐题填写和统计展示 |
| 后端 | Python、FastAPI | 提供接口，处理身份认证、业务规则和数据访问 |
| 数据库 | MongoDB、PyMongo | 保存用户、问卷配置和答卷，完成索引约束与聚合统计 |
| 认证 | Argon2、JWT | 保存密码哈希，识别已登录用户 |
| 测试 | pytest、FastAPI TestClient | 自动检查规则与接口，接口测试连接真实 MongoDB |

前后端同源运行。前端通过 `/api` 接口访问后端，后端读写 MongoDB。业务数据不使用关系数据库，也未采用现成问卷系统框架。

## 3. 用户与权限

| 使用场景 | 可以做什么 |
| --- | --- |
| 未登录用户 | 注册、登录；不能直接填写问卷 |
| 问卷创建者 | 管理自己创建的问卷，配置题目与规则，发布、关闭并查看统计 |
| 问卷填写者 | 登录后通过分享链接填写符合开放条件的问卷 |

创建者与填写者是使用场景，不是两个独立的账号类型。同一个账号既可以创建问卷，也可以填写问卷。管理列表只显示自己的问卷，不能凭其他问卷 ID 访问其管理数据和统计。

## 4. 功能模块

| 模块 | 已实现内容 |
| --- | --- |
| 账号 | 注册、登录、退出登录，用户名唯一及密码哈希保存 |
| 问卷管理 | 标题、说明、匿名与重复填写设置、截止时间、草稿保存、发布、关闭和分享链接 |
| 题目编辑 | 单选、多选、文本和数字填空，添加选项、删除及调整顺序 |
| 答案校验 | 必答、多选数量、文本长度、数字范围与整数、手机号纯数字字符 |
| 条件跳转 | 单选、多选和数字条件，按配置顺序匹配，仅向后跳转 |
| 填写提交 | 逐题回答、返回修改、自动跳转、错误提示和正式答卷保存 |
| 预览 | 创建者检查已保存的问卷流程，不生成正式答卷 |
| 统计 | 整份问卷或单题统计，选项次数、回答份数、填空内容与数字平均值 |

## 5. 基本使用流程

| 顺序 | 操作 |
| --- | --- |
| 1 | 注册并登录账号 |
| 2 | 创建问卷，填写基本信息与填写设置 |
| 3 | 添加题目、校验条件及跳转规则，保存后预览 |
| 4 | 发布问卷，在列表中复制分享链接 |
| 5 | 填写者登录后打开链接，填写并提交 |
| 6 | 创建者查看整体或单题统计，必要时关闭问卷 |

## 6. 第一阶段的处理约定

| 内容 | 约定 |
| --- | --- |
| 匿名 | 仍需登录；内部保留用户 ID，向创建者返回匿名答卷时隐藏账号身份字段 |
| 重复填写 | 默认不允许；允许时，每次成功提交都保存为独立答卷 |
| 发布后编辑 | 锁定题目、选项、规则、匿名和重复填写设置，仅允许修改标题、说明、截止时间及关闭 |
| 截止 | 数据库存 UTC，页面使用北京时间；以服务器检查时间为准 |
| 统计口径 | 按有效答卷份数统计，不按账号去重；未答和跳过的题目不计为数字 0 |
| 未提交数据 | 不保存服务端填写草稿；更改前题答案后需重新确认后续路径 |
| 访问范围 | 默认本机访问；分享链接用于本机演示，联网部署需另外配置 |

## 第二阶段页面与操作流程

本文说明第二阶段用户从哪里进入功能、每一步操作保存什么、失败时如何继续，并将页面操作与[接口设计](API说明.md#第二阶段接口契约与兼容说明)对应。基于现有 HTML、CSS、JavaScript 页面及 hash 路由扩展，不更换前端技术体系。

本文保留完整目标交互。题目管理、版本历史与恢复、原编辑器选题和换版本、共享、题库及跨问卷统计页面已实现，验证见[第二阶段实现与验证](../测试/测试用例.md#第二阶段实现与验证)。当前管理页的“加入新问卷”用于新建问卷；加入已有草稿从原问卷编辑器的选题器完成。已有问卷创建、填写和统计继续保留。

### 1. 页面入口与导航

登录后设置“我的问卷”“题目管理”“题库”“跨问卷统计”四个主入口，账号区保留当前用户名和退出。填写者通过 /survey/{code} 进入原填写流程，不需要浏览题目管理。

| 页面 | 路由 | 内容与进入方式 |
| --- | --- | --- |
| 我的问卷 | /# | 原列表，保留创建、编辑、预览、统计、分享链接及关闭 |
| 创建和编辑问卷 | /#new、/#edit/{sid} | 原编辑器增加保存题目、选题和明确替换版本操作 |
| 预览与问卷统计 | /#preview/{sid}、/#stats/{sid} | 保留原预览和统计；统计增加版本信息及单题授权入口 |
| 题目管理 | /#questions | “我的题目”“共享给我的”两个页签，支持关键词、类型展示和版本摘要 |
| 新建题目 | /#question-new | 题目编辑器，保存为 v1 |
| 题目详情 | /#question/{series_id} | 版本内容、历史、来源、使用情况；所有者另有共享和归档操作 |
| 基于版本编辑 | /#question/{series_id}/edit/{version_id} | 自有题保存新版本；共享题派生到自己名下 |
| 题库列表 | /#banks | 创建、编辑或删除自己题库 |
| 题库详情 | /#bank/{bank_id} | 名称、说明、成员、版本更新和加入问卷 |
| 跨问卷统计 | /#question-stats | 自有、共享、既有引用及收到统计授权的题目版本入口 |
| 具体版本统计 | /#question-stats/{version_id} | 汇总、来源、内容可见范围、数字分布 |

“题目共享”和“问卷分享链接”使用不同按钮名称。前者授权其他用户复用题目，后者把问卷链接给填写者。

选题器、题目共享和单题统计授权使用当前页面内弹窗，不单独增加复杂导航。管理页可把选题暂存到新建问卷的当前编辑页面；加入已有草稿时先打开该草稿，再从选题器选取。两种方式都需要最终保存问卷。

### 2. 每类操作的保存边界

| 操作 | 保存时机 | 影响范围 |
| --- | --- | --- |
| 输入题干、选项、校验 | 未点击保存前只在当前编辑界面 | 不改变正式版本 |
| 保存为版本 | 接口成功时 | 创建题目版本，不替换任何已有问卷或题库 |
| 在问卷中选题、换版本、调序、改跳转 | 点击“保存问卷”前只改变当前编辑草稿 | 保存成功后改变该份草稿 |
| 保存并发布 | 先保存题目版本及完整问卷，再调用发布 | 发布成功后锁定结构 |
| 加入或更新题库 | 点击“保存题库”时 | 只改变该题库成员，不改变问卷 |
| 共享、撤销共享、统计授权 | 在对应面板点击操作并成功后 | 当前授权立即更新，后续请求检查最新权限 |
| 恢复历史版本 | 明确点击“以此内容创建新版本”并成功后 | 新增版本，原版本、问卷及题库不变 |

页面对“题目已保存”和“问卷已保存”分别反馈，不用同一个“保存成功”掩盖多步操作的实际状态。已有题目版本是独立成果，离开未保存问卷不会自动删除它。

### 3. 题目管理与新建

题目管理默认“我的题目”，显示名称、最新题干、题型、最新版本、状态和创建时间。所有者可筛选 active 或 archived；“共享给我的”仅显示当前可用共享题，标注拥有者。

空列表给出“新建题目”；共享列表为空说明尚未收到可用共享，不把它写成系统故障。失败时保留筛选条件并提供重试，401 转登录并说明登录失效。

新建步骤：

1. 点击“新建题目”，输入管理名称，选择原四种题型，填写题干、必答、选项及校验。
2. 页面不显示问卷题序和跳转目标，因为它们属于具体问卷。
3. 点击“保存为版本”，调用 POST /question-series，成功显示系列详情和 v1。
4. 可以继续加入题库或选择问卷；这些是后续独立操作，不随保存题目自动执行。

编辑界面离开前提示未保存内容。按钮提交期间禁用重复点击；网络失败保留输入和本次请求键，重试查回同一产物，不能连续生成多个版本。

### 4. 版本历史、编辑与恢复

详情顶部展示当前选中版本、最新版本和状态；历史列表显示版本号、保存时间、操作类型、直接来源及恢复来源。允许展开对照题干、题型、必答、选项和校验的差异。

版本来源按实际关系显示，例如“v4 基于 v2”“v5 在 v4 基础上恢复 v1 内容”。历史有分支时，不把 v1、v2、v3 的编号顺序直接画成继承链。

| 操作 | 所有者 | 有效共享接收者 |
| --- | --- | --- |
| 查看已有版本 | 只读查看 | 只读查看 |
| 修改题目 | “基于此版本编辑”，保存到原系列的新版本 | “派生为我的题目”，保存为新系列 v1 |
| 恢复旧内容 | 展示当前基准与被恢复版本，点击“以此内容创建新版本” | 不恢复他人的系列；可以在有使用权时派生所选旧版本 |
| 分享或归档 | 可操作 | 不显示 |

进入编辑时可展开使用情况提示，说明现有问卷继续使用旧版本。保存后显示真实返回的版本号，不预先假定下一号必然连续。新版本保存成功后提供“返回问卷继续替换”或“更新题库”的入口，均需要明确选择，不自动替换。

归档后已有问卷保留；详情显示归档状态并禁止新增使用、派生和版本更新。所有者可取消归档。用户在旧页面遇到刚发生的归档或撤销时，保留尚未提交输入，显示当前操作已不可用，不把原始内容另存为无来源新题绕过限制。

### 5. 共享题目的操作

系列所有者在详情点击“共享使用”，查看已授权用户名及状态，输入接收者的准确用户名。

授权前展示：“对方可以使用这个题目系列的现有及后续版本，也可以派生为自己的题目；此操作不开放你的问卷回答。”点击“授予使用权”调用 shares PUT，成功后更新列表。

点击撤销时说明已有问卷和已完成派生保留，后续不再允许新增使用。共享接收者刷新后，该题从“共享给我的”消失；自己问卷和题库中已有条目仍显示原快照，并标注“共享已取消，仅保留原引用”。

不提供“修改原题”按钮给共享接收者。派生保存成功后显示新拥有者为当前用户，并记录原版本来源。

### 6. 在问卷编辑器中新增选题

原“添加一道题”按钮和直接编题流程保留，新增“从已有题目选取”和“从题库选取”。每个已绑定题目的标题旁显示版本号、来源及可用状态，内部 ID 不作为面向用户的主要标签。

选题器的来源为“我的题目”“共享给我的”“我的题库”；按系列先选具体版本，展示五项内容预览。题库中的不可用成员保留展示，但禁用“选用”并说明原因。

1. 选定版本后，前端生成新的问卷内部题目 ID，加入当前页面末尾；跳转规则为空。
2. 同一版本已在当前问卷时，禁用再次添加；同系列其他版本可以添加并明确标注。
3. 可继续调序、设置跳转。未保存问卷时，不提前写入服务器问卷。
4. 点击保存，后端重新检查版本、授权、快照和整份问卷规则；检查通过后整体保存。

从题目详情或题库点击“加入问卷”时先选择自己的草稿。若目标问卷当前有未保存编辑，先处理该编辑状态，不创建另一个页面覆盖；已发布和已关闭问卷不出现在可修改目标中。选择“新建问卷”只进入携带所选版本的新建编辑页，不自动创建空问卷。

### 7. 问卷内直接编题与修改

未绑定的新题仍可在原编辑器直接填写。在新编辑器保存问卷时：

1. 检查题目内容完整，识别新题和已修改题，跳过内容未改的版本。
2. 新题调用创建系列接口；自有题修改调用创建版本接口；共享题修改必须先进入“派生为我的题目”操作。
3. 取得真实版本后，把版本引用与题目快照放回当前页面的题目列表，再提交整份问卷。
4. 正式版本接口成功但问卷失败时，在相应题目上显示“版本已保存，问卷未保存”，保留返回的版本引用以便重试。

题目卡片提供“保存为版本并留在当前问卷草稿”操作，便于单独完成一个题目；页面提示该操作尚未保存整份问卷。取消编辑不会覆盖原正式版本。

已有共享题的原内容默认只读，题序和跳转仍可配置；用户选择派生后，内容编辑保存到自己的新系列。撤销共享的旧引用只能保持原内容、调整问卷配置或移除，不能再次派生或产生新引用。

### 8. 问卷内替换版本与规则修复

题目卡片显示“有新版本”时只提示，不改变当前绑定。用户点击“选择版本”，看到当前版本与目标版本差异，明确选择后在本地草稿中替换，保留内部题目 ID。

替换后保留现有跳转供检查，不自动清空或删除。页面标记该题自身失效的选项条件、题型不匹配的规则，以及题序调整导致的无效跳转；最终以后端整卷验证为准。

例如原题有选项 A，新版本删除 A，但原跳转条件仍引用 A：保存返回 INVALID_JUMP_RULE，定位到相应题目和规则，用户修正规则后再保存。原服务器草稿在失败时保持不变。

发布或关闭后的编辑器保留第一阶段元数据编辑，题目内容、版本、排序、跳转、匿名及重复填写设置只读；可以查看已绑定版本快照，不能通过“更新版本”绕过锁定。

“保存并发布”分步显示失败位置：版本保存失败则停在原编辑内容；问卷保存失败保留新版本引用；问卷保存成功但发布失败时明确显示“草稿已保存，尚未发布”，按发布错误修复，不重复创建问卷。

### 9. 题库管理

题库列表展示名称、说明、成员数和更新时间。创建空题库后进入详情，修改名称、说明、添加或移除成员均在当前页面暂存，点击“保存题库”整体提交并刷新 revision。

题库成员展示题干、题型、绑定版本和来源；加入已有题目使用同一选题器。单个版本不重复添加，同系列不同版本允许并存。

发现新版本时显示“可更新”，点击对比并选择目标版本后暂存在成员列表；保存成功只更新当前题库，原问卷和其他题库继续使用原版本。已撤销共享或归档条目标注原因，允许移出或保留，不允许再次选入问卷或更新。

并发冲突时保留本地未保存变更供核对，提示重新加载远端版本；不自动刷新并丢弃输入。删除题库前说明将移除容器，版本和已有问卷仍保留，提交带当前 revision。

### 10. 题目使用情况

题目详情中提供“使用情况”，可筛选全部版本或指定版本。每条展示版本、问卷标题、状态和允许的操作，数量口径标注为“问卷数”，同一问卷多版本的明细可以分行。

拥有者可看到自己问卷、已向自己授权统计的他人问卷，以及其余受限问卷的汇总数量；受限部分不显示标题、用户或链接。共享接收者仅看到自己的使用记录，不展示全局数量。

自己的问卷可点击管理或统计；他人仅授予单题统计的来源只能进入该版本统计，不进入他人编辑器或整卷统计。自己仍持有旧引用但共享已取消时，从问卷上下文查看自己的使用记录，不能借入口查看源版本历史。

### 11. 跨问卷统计页面

入口以具体版本为单位，支持关键词或系列筛选；每条标注版本、题型及可统计来源。仅收到单题统计授权的用户也能从这里进入，无需先进入题目管理。

详情顶部展示题目快照、版本号，选择“全部有权限来源”“我的问卷”“他人授权”。页面始终同时显示来源问卷数、总答卷数及本题有效回答份数，避免把未答人数算成答题人数。

| 题型 | 主区域 | 填写内容 |
| --- | --- | --- |
| 单选 | 每个选项次数及回答份数，沿用现有条形展示 | 无逐条列表 |
| 多选 | 每个选项次数，说明一次回答可含多个选项 | 无逐条列表 |
| 文本 | 有效回答份数及内容权限说明 | 仅显示有内容权限的来源 |
| 数字 | 回答份数、平均值、最小值、最大值及范围分布 | 仅显示有内容权限的来源 |

数字分布默认等宽 10 组；允许输入自定义边界，例如 18、35、60，展示“小于 18”“18 至不足 35”“35 至不足 60”“大于等于 60”。切换边界不改变答案或统计授权，非法边界保留输入并报错。

“查看来源”展示有权纳入的问卷题，按是否具有内容权限标记；“查看填写内容”分页显示值，不显示填写者、答卷编号、提交编号或逐条时间。若基础统计 100 份回答、仅 40 份允许查看内容，页面明确写“可查看 40 份内容，基础统计共 100 份回答”。

没有统计来源时显示“当前没有可统计的问卷”；有来源但没人答题时显示“暂无有效回答”；无内容权限时说明“未获得填写内容权限”。这些状态不能混成同一空列表提示。

同系列版本比较按版本分别展示，一次最多选择 4 个版本逐个读取，不提供所有版本相加的总平均值。权限变化后刷新清除旧结果，不能继续用旧统计缓存替代当前范围。

### 12. 单题统计授权面板

从自己的原问卷统计页选定一道题，点击“授权他人查看本题统计”。草稿或未迁移问卷显示原因并禁用入口；已发布或已关闭可操作。

面板显示当前题、绑定版本、已授权用户，输入精确用户名，默认只授予基础统计。文本或数字题可另勾选“允许查看本题的填写内容”，旁边说明不会显示填写者身份。

授权成功后对方在跨问卷统计入口可见该题，不获得其他题目、整卷统计或管理权。撤销仅影响对方后续查询，原答卷和题目使用权保持原状态。共享题目面板和统计授权面板独立，避免用户误以为两种授权相互附带。

### 13. 页面状态与提示

| 场景 | 页面行为 |
| --- | --- |
| 输入未保存而切换主导航、hash 或关闭页面 | 统一检查 dirty 状态并提示；不能只拦返回按钮却遗漏其他离开入口 |
| 401 | 清理失效登录态，转登录；不把 token 放进链接或导出内容 |
| 404 | 显示当前资源不可访问，提供返回；不回显他人的资源名称 |
| 授权撤销、系列归档或问卷锁定 | 刷新当前可操作项，保留尚未提交内容供用户核对，阻止不允许的提交 |
| 409 并发冲突 | 提示远端已改变，不用旧输入自动覆盖 |
| 422 题目或跳转错误 | 保留输入，定位题目、规则及字段，支持修改后重试 |
| 请求失败或 503 | 显示失败属于哪个保存步骤；保留输入，版本操作沿用相同请求键重试 |
| 双击提交或慢请求 | 相关按钮暂时禁用，完成后按最新状态恢复，不一律解锁原本受限按钮 |
| 未迁移旧问卷 | 原功能继续可用，版本复用和统计授权入口提示需先迁移；页面不运行迁移 |

各页继续使用原 escapeHtml 处理用户题干、选项、用户名和回答；键盘可操作弹窗、关闭时回到原按钮，错误消息使用可感知的提示区域。实际页面验证见《测试用例.md》的第二阶段实现与验证；后续新增页面继续按这些要求验收。

### 14. 页面操作与验收对应

| 需求 | 完整操作链 | 验收重点 |
| --- | --- | --- |
| F1 保存复用 | 新建题目 → 保存 v1 → 问卷 A、B 选入 → 分别保存 | 同版本身份一致、问卷内部 ID 独立 |
| F2 共享 | 甲授权乙 → 乙选入或派生 → 甲撤销 | 原题不被覆盖，旧引用保留，新使用被拒绝 |
| F3 保护旧问卷 | A 使用 v1 发布并收回答 → 保存 v2 | A 的内容、答案和统计不改变 |
| F4 历史恢复 | 基于旧版本编辑 → 查看来源 → 恢复历史内容 | 新版本产生，旧历史不丢失，页面显示真实来源 |
| F5 多版本并存 | A 用 v1、B 用 v2 → 草稿主动换版本 | 不自动跟随最新，发布后的版本不能换 |
| F6 使用查询 | 详情查看使用 → 进入有权访问的上下文 | 明细和数量口径正确，不越权跳转 |
| F7 题库 | 建题库 → 加版本 → 选题建卷 → 更新题库成员 | 更新只影响当前题库，问卷保持原版本 |
| F8 跨问卷统计 | 同版本用于 A、B → 授权指定题 → 查询汇总及内容 | 按权限范围、版本和回答份数统计，内容权限单独生效 |

开发先完成题目管理和原编辑器接入，再添加共享与题库，最后完成使用情况及跨问卷统计；各批次都保留第一阶段原操作路径的回归验证。

## 7. 自动测试执行方式

在“Project1/Stage1/代码”目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

本机测试连接为 mongodb://127.0.0.1:27018，需要先启动专用 MongoDB；可先运行系统启动入口。新环境在虚拟环境中安装 requirements-dev.txt 后执行 python -m pytest -q，可通过 TEST_MONGO_URI 修改测试连接。

此前真实运行输出为：43 passed, 1 warning。提示来自当前 Starlette 对 httpx 测试客户端的弃用提醒，不影响测试通过。43 项包括规则测试与自动化 API 测试，不是两组各 43 项。

# 系统说明

## 1. 系统简介

本系统是基于 MongoDB 的简化在线问卷系统。用户登录后可以创建和发布问卷，将链接分享给其他登录用户填写，并查看已提交答卷的统计结果。界面以完成问卷业务为主，支持第一阶段需求，后续可在现有结构上扩展。

## 2. 技术组成

| 部分 | 使用技术 | 作用 |
| --- | --- | --- |
| 前端 | HTML、CSS、JavaScript | 登录、问卷编辑、逐题填写和统计展示 |
| 后端 | Python、FastAPI | 提供接口，处理身份认证、业务规则和数据访问 |
| 数据库 | MongoDB、PyMongo | 保存用户、问卷配置和答卷，完成索引约束与聚合统计 |
| 认证 | Argon2、JWT | 保存密码哈希，识别已登录用户 |
| 测试 | pytest、FastAPI TestClient | 自动检查规则与接口，接口测试连接真实 MongoDB |

前后端同源运行。前端通过 `/api` 接口访问后端，后端读写 MongoDB。业务数据不使用关系数据库，也未采用现成问卷系统框架。

## 3. 用户与权限

| 使用场景 | 可以做什么 |
| --- | --- |
| 未登录用户 | 注册、登录；不能直接填写问卷 |
| 问卷创建者 | 管理自己创建的问卷，配置题目与规则，发布、关闭并查看统计 |
| 问卷填写者 | 登录后通过分享链接填写符合开放条件的问卷 |

创建者与填写者是使用场景，不是两个独立的账号类型。同一个账号既可以创建问卷，也可以填写问卷。管理列表只显示自己的问卷，不能凭其他问卷 ID 访问其管理数据和统计。

## 4. 功能模块

| 模块 | 已实现内容 |
| --- | --- |
| 账号 | 注册、登录、退出登录，用户名唯一及密码哈希保存 |
| 问卷管理 | 标题、说明、匿名与重复填写设置、截止时间、草稿保存、发布、关闭和分享链接 |
| 题目编辑 | 单选、多选、文本和数字填空，添加选项、删除及调整顺序 |
| 答案校验 | 必答、多选数量、文本长度、数字范围与整数、手机号纯数字字符 |
| 条件跳转 | 单选、多选和数字条件，按配置顺序匹配，仅向后跳转 |
| 填写提交 | 逐题回答、返回修改、自动跳转、错误提示和正式答卷保存 |
| 预览 | 创建者检查已保存的问卷流程，不生成正式答卷 |
| 统计 | 整份问卷或单题统计，选项次数、回答份数、填空内容与数字平均值 |

## 5. 基本使用流程

| 顺序 | 操作 |
| --- | --- |
| 1 | 注册并登录账号 |
| 2 | 创建问卷，填写基本信息与填写设置 |
| 3 | 添加题目、校验条件及跳转规则，保存后预览 |
| 4 | 发布问卷，在列表中复制分享链接 |
| 5 | 填写者登录后打开链接，填写并提交 |
| 6 | 创建者查看整体或单题统计，必要时关闭问卷 |

## 6. 第一阶段的处理约定

| 内容 | 约定 |
| --- | --- |
| 匿名 | 仍需登录；内部保留用户 ID，向创建者返回匿名答卷时隐藏账号身份字段 |
| 重复填写 | 默认不允许；允许时，每次成功提交都保存为独立答卷 |
| 发布后编辑 | 锁定题目、选项、规则、匿名和重复填写设置，仅允许修改标题、说明、截止时间及关闭 |
| 截止 | 数据库存 UTC，页面使用北京时间；以服务器检查时间为准 |
| 统计口径 | 按有效答卷份数统计，不按账号去重；未答和跳过的题目不计为数字 0 |
| 未提交数据 | 不保存服务端填写草稿；更改前题答案后需重新确认后续路径 |
| 访问范围 | 默认本机访问；分享链接用于本机演示，联网部署需另外配置 |

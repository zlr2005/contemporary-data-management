# 功能清单

前半部分保留第一阶段说明，第二阶段新增内容追加在后文对应章节；当前运行环境见[配置说明](../代码/配置说明.md)。

## 1. 用户账号

- 支持用户注册账号。
- 支持用户登录账号。
- 每个用户至少保存用户名、密码和注册时间。（密码字段应保存密码哈希，不应保存明文）
- 用户可以使用自己的账号创建问卷。
- 用户可以查看自己创建的问卷。
- 用户可以查看自己问卷的统计结果。
- 用户登录后，只能看到自己创建的问卷，不得查看其他用户的问卷管理列表及统计结果。

## 2. 问卷创建与管理

- 支持创建问卷。
- 创建时可以填写问卷标题。
- 创建时可以填写问卷说明。
- 可以设置是否允许匿名填写。
- 可以查看自己创建的问卷列表。
- 可以发布问卷。
- 可以设置问卷截止时间。
- 可以关闭问卷。
- 每份问卷具有可访问的链接，例如 `/survey/xxxxxx`。
- 创建者可以将链接分享给他人填写。
- 填写者需要先登录。

## 3. 题目及答案校验

### 3.1 通用能力

- 一个问卷可以包含多个题目。
- 可以向问卷中添加不同类型的题目。
- 至少支持单选题、多选题、填空题三种题型。
- 填空题支持文本填空和数字填空。

### 3.2 单选题

- 可以设置单选题的选项。
- 填写者可以从选项中选择一个答案。
- 可以设置单选题是否必须回答。
- 必答单选题未选择答案时，系统进行校验并提示错误。

### 3.3 多选题

- 可以设置多选题的选项。
- 填写者可以选择多个选项。
- 可以设置至少选择多少个选项，例如至少 2 个。
- 可以设置最多选择多少个选项，例如最多 3 个。
- 可以设置必须选择多少个选项，例如必须选择 2 个。
- 填写时检查选择数量是否符合配置要求，不符合时提示错误。

### 3.4 文本填空题

- 可以创建文本填空题。
- 可以设置最少输入字数。
- 可以设置最多输入字数。
- 填写时检查文本长度是否符合配置要求，不符合时提示错误。

### 3.5 数字填空题

- 可以创建数字填空题。
- 可以设置允许输入的最小值。
- 可以设置允许输入的最大值。
- 可以设置是否必须为整数。
- 填写时检查输入是否合法，包括数字格式、范围和整数要求，不符合时提示错误。
- 能表达老师给出的校验示例：年龄为整数，且在 0～120 之间。
- 能表达老师给出的校验示例：手机号必须为整数。

- 问卷创建者可以在问卷中配置跳转规则，跳转逻辑不能写死在程序中。
- 支持根据单选题的选择结果跳转到不同题目。
- 支持根据多选题的选择结果跳转到不同题目。
- 支持根据数字填空题的内容跳转到不同题目。
- 填写时根据实际答案自动跳转到对应题目。
- 能配置并执行老师给出的示例：第 1 题选 A，跳到第 5 题；第 1 题选 B，跳到第 3 题。

## 5. 问卷填写与提交

- 填写者可以通过问卷链接进入问卷。
- 填写者可以按顺序回答题目。
- 填写过程中根据问卷规则进行跳转。
- 填写不符合要求时，系统提示错误。
- 填写完成后可以提交问卷。
- 保存每次提交的答卷。
- 支持多人同时填写问卷。
- 支持匿名填写。
- 支持在允许的情况下，同一个人多次填写问卷。

## 6. 统计结果

### 6.1 统计范围与访问

- 问卷创建者可以查看问卷统计结果。
- 支持查看整个问卷的统计。
- 支持查看某一道题的统计。
- 根据已经填写并保存的数据自动生成统计结果。

### 6.2 单选题统计

- 显示每个选项有多少人选择。
- 显示该题总共有多少人回答。

### 6.3 多选题统计

- 显示每个选项被选择多少次。

### 6.4 填空题统计

- 可以查看所有填写内容。
- 数字填空题可以查看平均值。

## 7. 第一阶段设计约定

以下方案已作为本项目第一阶段的实现依据，是本项目对需求细节的明确约定。

### Q1 登录与匿名填写

- 所有填写者都必须先登录。
- 匿名表示对问卷创建者隐藏填写者身份，不表示免登录。
- 系统内部保存填写者用户 ID，用于限制重复提交。
- 匿名问卷的答卷页面和统计接口不返回填写者用户名、用户 ID 等身份信息。

### Q2 重复填写

- 由问卷创建者设置是否允许重复填写，默认不允许。
- 根据登录账号的用户 ID 判断是否为同一个人。
- 允许重复填写时，每次成功提交均保存为独立答卷。
- 不允许重复填写时，由后端保证限制有效，同时发起的重复请求也不能绕过限制。

### Q3 多选跳转匹配

- 支持“包含任一指定选项”“包含全部指定选项”“与指定选项完全一致”三种匹配方式。
- 创建规则时选择匹配方式，默认采用“包含任一指定选项”。
- “包含全部”允许答案包含额外选项，“完全一致”要求答案与条件指定的选项集合相同，不考虑选择顺序。
- 例如条件为 `{A, B}`，答案为 `{A, C}` 时，只满足“包含任一指定选项”；答案为 `{A, B, C}` 时满足“包含任一”和“包含全部”，不满足“完全一致”。

### Q4 数字跳转条件

- 支持等于、不等于、大于、大于等于、小于、小于等于和区间判断。
- 区间采用闭区间，包含上下界；保存配置时检查下界不大于上界。
- 未填写的可选题不触发数字跳转条件。

### Q5 规则优先级与默认行为

- 按创建者配置的顺序，从上到下判断跳转规则。
- 第一条匹配的规则生效，不再继续匹配后续规则。
- 界面明确提示“从上往下匹配”。
- 没有规则命中时进入下一题；最后一题没有跳转时进入提交环节。

### Q6 跳转方向与循环

- 第一阶段的规则只允许跳到后面的题目，不允许跳到自身或前面的题目。
- 保存配置时检查跳转方向，以避免循环跳转。
- 填写者可以通过“上一题”返回实际答题路径中的前一道题修改答案；这不属于规则向前跳转。

### Q7 跳过必答题与旧路径答案

- 只校验实际答题路径上的必答题，被跳过的题目免于必答校验。
- 修改前面题目的答案后，重新计算答题路径，并清除不再处于有效路径上的答案。
- 提交时由后端重新计算路径、检查有效路径中的答案，仅保存有效路径中的答案。

### Q8 各题型的必答设置

- 单选、多选、文本填空、数字填空均支持单独设置必答，默认非必答。
- 可选题为空时免于格式、长度和范围校验；一旦填写，就必须符合配置要求。
- 多选题设置“至少选 2 个”或“必须选 2 个”等正数数量要求时，该要求本身意味着不能留空，界面同步体现其必答状态。
- 多选题的必答设置和数量限制不得互相冲突。

### Q9 问卷状态、截止时间与时区

- 草稿只允许问卷创建者预览，不接受正式提交。
- 只有已发布、未关闭且未到截止时间的问卷允许填写和提交。
- 已关闭或已过期的问卷显示原因，并禁止提交。
- 开始填写时尚未截止、提交时已截止的答卷，也拒绝接收。
- 时间设置和展示采用北京时间 `Asia/Shanghai`，数据库采用 UTC 保存时间。
- 以服务器检查提交时的时间为准，到达截止时刻即停止接收。

### Q10 首次发布后的修改范围

- 首次发布后，锁定题目、选项、校验规则、跳转规则、匿名设置和重复填写设置。
- 发布后仅允许修改标题、说明、截止时间，以及关闭问卷；其他既有权限和截止检查仍然生效。
- 需要调整题目结构时，新建一份问卷，保留原问卷及其答卷。
- 第一阶段以此保证旧答卷与问卷结构一致；第二阶段如有相关新需求，再扩展版本机制。

### Q11 手机号校验与存储

- 手机号按字符串保存，保留前导零。
- 输入仅允许 `0–9`，不允许小数点、正负号、空格或字母；此规则用于落实老师示例中的整数输入要求。
- 手机号不参与数字平均值等计算。
- 普通数字填空仍按数值处理，并按配置执行整数和范围校验。

### Q12 统计口径

- 按成功保存的有效答卷统计，不按填写账号去重。
- 同一账号在允许重复填写时，每次成功提交均独立计数。
- 单选题每个选项的计数表示选择该选项的答卷份数；该题总回答份数仅包含实际回答该题的答卷。
- 多选题每个选项的计数表示包含该选项的答卷份数。
- 界面使用“选择次数”“回答份数”等明确表述，并说明每次提交独立计数。
- 如果老师后续明确要求按填写者去重，则再增加按账号去重的统计指标。

### Q13 文本长度与未回答题目的统计

- 文本先去除首尾空白，再按 Unicode 码点数计算长度。
- 中英文、数字、标点均计入，内部空格和换行各计一个。
- 前后端采用相同的文本处理及计数规则。
- 未回答及被跳过的题目，不计入该题有效回答数，不出现在填空内容列表中，也不参与数字平均值。
- 数值 `0` 是有效答案，必须参与统计及平均值计算。
- 没有有效数字答案时，平均值显示“暂无数据”。

## 第二阶段新增功能

以下追加第二阶段八项已实现功能，前文第一阶段功能继续保留；业务规则详见[第二阶段需求梳理](第二阶段需求梳理.md)。

| 需求          | 已实现行为                                                                               | 操作入口                             |
| ------------- | ---------------------------------------------------------------------------------------- | ------------------------------------ |
| F1 保存与复用 | 独立系列与不可变版本；同版本用于多份问卷，同卷不重复引用同版本                           | 题目管理、问卷编辑器“从已有题目选取” |
| F2 共享       | 按注册用户名授予系列当前及后续版本使用权；接收者修改时派生自己的系列，保留来源           | 题目详情“共享使用”、“共享给我的”页签 |
| F3 发布后保护 | 首次发布后锁定结构与题目；新版本、题库升级不影响原问卷、答案和统计                       | 原问卷编辑器、发布与关闭流程         |
| F4 历史与恢复 | 显示直接来源、恢复来源；恢复旧内容创建新版本，保留已有历史；有权时展开派生来源名称与版本 | 题目详情、版本编辑器                 |
| F5 多版本并存 | 草稿主动选版本，原内部题目 ID 保持；不同版本各自保存及统计                               | 原编辑器版本替换                     |
| F6 使用情况   | 分版本查询，展示可查看问卷；受限他人使用只提供允许的数量，不泄露问卷信息                 | 题目详情“问卷使用情况”               |
| F7 题库       | 创建、编辑、删除自己的题库；添加、移除和主动更新成员版本，保留快照                       | 题库、原编辑器“从题库选取”           |
| F8 跨问卷统计 | 具体版本汇总、权限范围筛选、来源与内容分页、数字分布；同系列最多四个版本分别对比         | 跨问卷统计、原统计页                 |

管理页“加入新问卷”创建当前编辑页中的问卷草稿。向已有草稿加题，先打开该草稿再选题。选题、换版本和设置跳转后仍须保存整份问卷。共享题原内容只读，显式派生后才能编辑自己的题目。

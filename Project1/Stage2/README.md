## 主要功能

- 账号注册与登录，管理操作检查问卷所有权。
- 创建和发布问卷，配置匿名、重复填写及截止时间。
- 支持单选、多选、文本和数字题，配置必答、数量、长度、格式及数值限制。
- 根据单选、多选和数字条件跳转，按规则顺序首条命中，仅允许向后跳转。
- 后端重新计算有效答题路径，校验答案并保存答卷，支持提交重试和并发防重复。
- 查看整份问卷或单题统计，包括选项次数、填写内容及数字平均值。
- 独立保存题目及版本，在多份问卷中选择同一版本。
- 基于旧版本修改形成分支；恢复旧内容时生成新版本，保留历史来源。
- 草稿主动替换题目版本，保留问卷内部题目 ID，并重新检查整卷跳转。
- 查询自有题目的问卷使用情况，归档后保留原问卷和答卷。
- 向注册用户共享题目及后续版本；接收者可复用，修改时派生为自己的题目。
- 创建题库、添加或移除题目、主动更新成员版本，并从题库选题建卷。
- 独立授予某份问卷中某题的统计权限，可另行开放填空内容。
- 按具体版本汇总有权查看的多份问卷，查看来源、内容及数字分布；同系列最多四个版本分别对比。

## 环境准备与启动

以下以 Windows PowerShell 为例，需要安装 Python 3.10及以上版本（含可用的 pip）和 MongoDB Community Server。将 `mongod` 所在目录加入 PATH；若未加入，可在启动前设置其实际路径：

```powershell
$env:MONGOD_PATH = "你的MongoDB安装目录\bin\mongod.exe"
```

在本 README 所在目录打开终端，进入“代码”目录并准备独立环境：

```powershell
cd 代码
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start.py
```

之后也可双击“代码”目录中的 `启动系统.cmd`（需保证 `python` 命令可用）。启动入口会优先使用已有项目虚拟环境；缺少可用环境时，会尝试创建环境并安装依赖。

启动后访问：

- [问卷系统](http://127.0.0.1:8001)
- [交互式API文档](http://127.0.0.1:8001/docs)

默认连接 `mongodb://127.0.0.1:27018`，使用 `questionnaire_stage2` 数据库。该端口没有数据库服务时，启动入口会尝试启动仅监听本机的专用 MongoDB 实例，数据保存在“代码/.data/local-mongo”。应用启动时自动初始化集合校验和索引，不会自动迁移旧库。

如需连接已有 MongoDB，将“代码/.env.example”复制为同目录下的 `.env`，修改 `MONGO_URI`、`MONGO_DATABASE` 和 `APP_PORT`。第二阶段应保持独立库名。详细说明见[配置说明](代码/配置说明.md)。

仓库不包含本机数据库数据，其他电脑首次运行需自行注册和建卷。当前开发机曾迁入原有 3 个账号、4 份问卷和 8 份答卷；这些账号与数据不随提交副本分发。浏览器自动测试账号和答卷仅存在临时测试库，测试结束已清理。

## 基本使用流程

1. 注册并登录，创建问卷。
2. 添加题目，设置选项、校验和跳转规则，保存草稿并预览。
3. 发布问卷，在列表中复制分享链接。
4. 登录填写者账号，通过链接填写并正式提交。
5. 切回创建者账号，打开统计页核对选项次数、内容和平均值。

登录后还可进入“题目管理”保存题目并维护版本。在问卷编辑页点击“从已有题目选取”，明确选择一个版本；保存题目版本后仍需保存整份问卷。已有题目修改会生成新版本；已发布或已关闭问卷保持原版本。

题目详情的“共享使用”授予复用权；问卷统计页的“授权本题统计”授予答卷统计权，两者相互独立。跨问卷统计仅汇总自己的问卷和明确授权的单题。题库版本变化不会自动改变已有问卷；撤销共享后，已有问卷引用仍可正常发布、填写和统计。

匿名填写仍需登录，匿名表示向创建者隐藏填写者账号身份。默认服务仅监听本机，分享链接用于本机演示；跨电脑访问需要另外部署和配置网络。

## 兼容旧功能与当前边界

首次发布后继续锁定题目结构和填写设置，仅允许修改标题、说明、截止时间及关闭问卷。问卷内部题目 ID 和原答卷答案结构不变；新增系列和版本引用不进入填写端。未迁移的旧问卷仍可使用原阶段功能，新增复用功能需先通过迁移脚本建立关联。

共享使用权不包含他人的答卷访问权；跨用户填空内容不返回填写者身份、答卷编号和逐条提交时间。不同版本分别统计，不合并平均值。

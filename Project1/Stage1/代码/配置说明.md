# 问序：基于 MongoDB 的问卷系统

使用 Python、FastAPI、PyMongo 和原生 HTML/CSS/JavaScript，实现第一阶段功能清单。前后端同源运行，所有业务数据保存到 MongoDB。

## 启动

首次使用请先按上级目录 README 的步骤安装依赖。完成环境准备后，双击 `启动系统.cmd`，或在本目录终端执行：

```powershell
python start.py
```

随后访问：

- 网页：http://127.0.0.1:8000
- 可交互 API 文档：http://127.0.0.1:8000/docs

启动入口会检测项目或上级目录的虚拟环境。没有可用环境时创建本项目 `.venv` 并安装依赖，需要 Python 3.10 以上及可用的 pip。默认需要 `mongod` 在 PATH 中，也支持设置 `MONGOD_PATH`；本机安装位置另有兼容检测。MongoDB 未启动时，以隐藏进程启动项目专用实例，端口 27018，数据目录 `.data/local-mongo`，不会使用之前课程实验的数据目录。停止后端后保留数据库进程和数据，再次启动会复用。

默认仅监听本机，因此分享链接用于本机演示。局域网或公网访问需要另行配置监听地址、域名与部署环境。

配置其他数据库时，将 `.env.example` 复制为 `.env` 后修改。已有 MongoDB 使用 27017 时，可设置 `MONGO_URI=mongodb://127.0.0.1:27017`，不会再自动启动专用实例。系统启动时创建集合、validator 和索引。JWT 密钥未设置时自动保存到 `.local-secret`，它不属于业务数据，不要提交该文件。

## 使用流程

1. 注册并登录，密码至少 8 个字符。
2. 创建问卷，填写标题、说明、北京时间截止时间和填写设置。
3. 添加题目，设置选项、必答与校验条件。
4. 在来源题目下添加跳转规则，选择条件与后面的目标题目。规则从上往下匹配；多选条件按 Ctrl 选择多个选项。
5. 保存后预览。预览验证实际流程，不保存正式答卷。
6. 保存并发布，返回列表复制分享链接。
7. 填写者登录后填写并提交。在统计页面查看整份问卷、单题统计及填空内容。

开发阶段曾使用演示账号和问卷验证功能；仓库不包含本地数据库，因此新环境中没有预置账号或答卷，请自行注册并创建问卷。

## 测试

按上级 README 在“代码”目录创建 `.venv` 并安装开发依赖后，先启动 MongoDB，再在本目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

新环境需先在虚拟环境中安装 `requirements-dev.txt`，再执行 `python -m pytest -q`。可通过 `TEST_MONGO_URI` 修改测试连接。每项接口测试使用独立的随机 `questionnaire_test_*` 数据库，并仅清理本次测试数据库，不清理正式数据库。测试必须连接真实 MongoDB，没有用内存假数据库代替。

本次自动测试结果为 43 项通过；当前依赖的 Starlette 对测试使用 httpx 给出弃用提示，不影响测试通过。测试步骤、输入、输出及已执行结果见[《测试/测试用例.md》](../测试/测试用例.md)，详细手工操作见[《测试/手工操作与截图指南.md》](../测试/手工操作与截图指南.md)；学生手工验收结果需结合实际操作及[截图](../测试/手工测试截图/)核对。

## 第二阶段如何扩展

- 题型：在 `domain.py` 添加处理器并注册到 `HANDLERS`，提供配置检查与答案规范化；再补数据库题型校验、前端输入控件、统计方式和测试。
- 跳转：在 `OPERATORS` 中增加通用运算符，并在处理器中声明可用条件及其配置校验，不添加针对某份问卷的判断。
- 生命周期和权限：集中修改 `services.py`，不把限制仅写在前端按钮上。
- 数据迁移：保留 `schema_version` 和稳定题目、选项 ID。新字段通过迁移脚本补齐，保留旧数据和第一阶段行为。
- 发布后改题：第一阶段锁定结构。第二阶段如需开放，应增加内容版本及答卷版本关联，不能直接覆盖旧题目。

## 当前边界

不保存未提交填写草稿；返回修改前题且更改答案时，清除其后缓存并重新填写后续路径。问卷发布后只允许修改标题、说明、截止时间和关闭。关闭与提交按服务器读取检查时刻判定，已通过检查的并发请求可能继续入库，与数据库设计约定一致。

统计按答卷份数计数。匿名针对创建者的账号身份展示，内部仍保存填写者 ID；题目中主动填写的个人信息不会自动消除。手机号按纯数字文本处理，不参与数字平均值。
